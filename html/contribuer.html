Pour contribuer

✦

Le projet est ouvert aux contributions et aux suggestions. Pour les suggestions, rendez-vous dans l'onglet suggestions. Deux modes de contribution sont possibles : une contribution libre via formulaire et une contribution directe via un tableur Grist pour les utilisateurs autorisés.

Suggestions

Accéder au formulaire de suggestions →

  • Des problèmes liés à l'ergonomie générale et/ou à l'utilisation du site.
  • L'ajout de nouvelles fonctionnalités de filtrage des textes.
  • L'ajout de nouvelles thémamtiques ou mots-clés grammaticaux.
  • Des précisions sur l'utilisation, notamment pédagogiques, des textes référencés ou plus généralement de la base de texte.
  • Des demandes d'accès aux fichiers TEI et/ou html ou aux code source.
  • Toute remarque pertinente au projet TNR.
Contribution libre

Accéder au formulaire de contribution →

Avant tout dépôt, il est conseillé de consulter le sommaire des textes référencés. Cette consultation permet d'éviter de présenter un dépôt déja existant, mais aussi de consulter les noms d'auteurs et les titres d'oeuvres anciennes retenues pour les contributions existantes.

  • Crédit contribution : indiquer le prénom et le nom du·de la contributeur·rice sous la forme Prénom Nom (majuscules à l'initiale). Il est possible de déposer anonymement, mais il est conseillé de renseigner son nom pour le suivi des informations et la valorisation de la participation.
  • Langue : sélectionner Latin ou Grec.
  • Auteur : renseigner le nom de l'auteur en français si existant (ex. Aulu-Gelle et non Gellius). Sinon, renseigner le nom de l'auteur en latin.
  • Œuvre ancienne : renseigner le titre de l'œuvre en français si existant. Sinon, renseigner le nom de l'œuvre dans la langue source.
  • Référence : entrer les références du texte en utilisant des chiffres arabes. Le séparateur d'usage est le point. Ne pas utiliser les notations p., § ou v. (ex. 1.114-1.138 ou 2.56).
  • Prose/poésie : choisir l'option adéquate.
  • Genre : choisir un ou plusieurs genre(s) littéraire(s) pour le texte. Si un genre souhaité n'apparaît pas, le renseigner dans la case « Nouvelles catégories ».
  • Titre du texte : indiquer un titre pour le texte proposé, au choix du·de la contributeur·rice.
  • Niveau : sélectionner le niveau du texte. Voir la rubrique Niveaux de difficulté dans la documentation.
  • Nombre de mots : indiquer le nombre de mots approximatif du texte. Ne pas spécifier « environ ».
  • Coupes : si le texte proposé a subi des coupes [...], cocher la case.
  • Texte latin / grec : renseigner le texte original. En prose, ne pas mettre de sauts de paragraphe ; en poésie, utiliser un saut de paragraphe entre les vers (sans séparateur /).
  • Traduction : renseigner la traduction. Même règles que pour le texte original (prose / poésie).
  • Crédit édition : spécifier l'éditeur, le manuel, le site dont est issu l'extrait.
  • Crédit traduction : renseigner le prénom et le nom du·de la traducteur·rice sous la forme Prénom Nom. Si la traduction n'est pas personnelle, indiquer le traducteur et/ou l'édition/le site.
  • Thèmes du programme d'enseignement secondaire : choisir une ou plusieurs thématiques. Champ réservé aux textes utilisés dans l'enseignement secondaire, voir la documentation ministérielle pour le collège et le lycée.
  • Thèmes : choisir une ou plusieurs thématique(s) pour le texte. Pour l'explicitation des thématiques, voir la rubrique Thématiques dans la documentation.
  • Conjugaison / Morphologie / Syntaxe : renseigner les points remarquables que présente le texte. Une liste d'items est proposée. Si un item souhaité n'apparaît pas, le renseigner dans la case « Nouvelles catégories ».
  • Utilisation pédagogique : décrire s'il y a lieu, les aménagements textuels effectués par l'enseignant ; les ressources annexes utilisées ; les points grammaticaux remarquables... Restez aussi concis que possible.
  • Nouvelles catégories : indiquer, au besoin, les items manquants pour les listes Genre / Thèmes / Conjugaison / Morphologie / Syntaxe. Séparateur : saut de paragraphe.
